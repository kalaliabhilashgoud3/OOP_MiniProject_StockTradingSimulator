# Stock Trading Simulator 2.0

**MNR University · OOP Java · II-Year I-Semester**

## Project overview

This is an upgrade to the existing Stock Trading Simulator repository. It models a paper-trading platform where buy and sell requests are handled with price-time priority, account balances and holdings are updated, and each completed trade is recorded. All quotes, indices, account money, and execution liquidity are simulated offline. The application does not connect to NSE/BSE or place real trades.

The desktop UI uses Java Swing and JFreeChart. The service layer handles matching, market simulation, account ledger, analytics, and persistence. CSV files remain the source of project data so the sample files stay easy to inspect and edit. SQLite was considered, but CSV is sufficient for this single-user teaching simulator and keeps the existing import/export workflow simple; writes are atomic and readable backups are kept beside each saved file.

## Features

- Dashboard cards for cash, investment, portfolio value, total and daily P/L, and trade count; simulated NIFTY 50, SENSEX and BANK NIFTY; portfolio chart and market movers.
- Searchable and sortable Indian sample-stock market table with previous close, open, day range, change, volume, simulated market cap and 52-week range; persisted one-shot price alerts.
- Multiple named watchlists, stock details, line/candlestick/volume charts, and 1D through ALL chart filters.
- Market, limit, stop-loss and stop-limit orders, price-time priority, partial fills, order status history, cancel/refund, best bid/ask and depth view.
- Virtual deposits and withdrawals, holdings with average cost, realized and unrealized P/L, trade and transaction history, CSV trade export, account analytics, and leaderboard.
- Configurable simulation speed, open/closed state, default trader, alert preference, light/dark theme and rupee display format. Settings are persisted. The settings page can make a ZIP backup of CSV data or reset market-session stats while keeping accounts and trade history. Activity feed entries are generated by the simulator and are not external news.
- CSV persistence for accounts, portfolios, orders, trades, transactions, watchlists, price history, performance and simulation preferences. Saves use a temporary file and atomic replacement where supported; readable previous files are backed up as `.bak`.

## Requirements and run

Install JDK 17 or later and Maven 3.8+. From the project folder:

```powershell
mvn test
mvn package
java -jar stocksim.jar
```

The Maven package step creates a self-contained `target/stocksim.jar` with the main class and JFreeChart. The root `stocksim.jar` is the convenience copy used by the desktop launcher; `build_windows.bat` refreshes it after a successful Maven build.

If you use the included local Maven distribution from this development workspace, run `work\apache-maven-3.10.0\bin\mvn.cmd test` or `work\apache-maven-3.10.0\bin\mvn.cmd package` instead.

## Windows desktop icon

To install a desktop shortcut that starts the simulator, run:

```powershell
powershell -ExecutionPolicy Bypass -File .\create_desktop_shortcut.ps1
```

It places `StockTradingSimulator.lnk` and its `.bat` launcher on the Desktop. Double-click the shortcut icon to open the app. It uses the bundled `stocksim.jar` and requires Java 17+.

For a packaged Windows app-image, run `build_windows.bat` with JDK 17+ and Maven available on PATH. The result is `dist\StockTradingSimulator`; it uses `jpackage --type app-image --icon icon.ico`, which does not require WiX. EXE/MSI packaging is optional and requires WiX.

`icon.png` and `icon.ico` provide the stock-chart icon used by Swing and the Windows package.

## Tests

Run `mvn test`. JUnit 5 covers crossing and non-crossing limits, priority, negative prices, insufficient cash and shares, cancel/refund, partial fills, market execution, stop triggers, simulated price updates, CSV recovery, and platform persistence/reload.
